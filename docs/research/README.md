## 核心发现 TOP 5

1. **全行业空白一**：没有任何备份工具能让用户「看见备份了什么」（01 §10.1 / 06 章）。
2. **全行业空白二**：密钥恢复零工具支持，「密码丢=数据全丢」横跨所有产品（01 §10.2 / 03 §2.3）。
3. **2026 最大信任危机**：Backblaze 静默排除云同步文件夹（HN 千赞）——「覆盖契约透明化」是直接对位（02 §八.1）。
4. **技术最优解公开**：FastCDC、pack 打包、envelope 加密、分代 GC 全部有成熟先例，组合即可（03/04 章）。
5. **云成本真相**：B2 $6.95/TB/月 + R2 零出口恢复 = 个人双云 3-2-1 最优；恢复成本必须放首屏（05 §1）。
