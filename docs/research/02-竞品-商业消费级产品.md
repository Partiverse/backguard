# 02 · 竞品调研（二）：商业消费级与系统自带备份产品

> 调研时间：2026-09。方法：官网定价页直接抓取 + Reddit/HN/博客痛点抽样。部分站点（iDrive、Acronis 官网动态定价、HN 原帖）抓取受限，相关数字以 2026 年评测/经销商数据交叉印证。
> 关联：[01 开源竞品](01-竞品-开源备份工具.md)、[05 云端多端](05-云端多端与传输.md)、[07 产品定位](07-产品定位与竞争优势.md)。

## 一、系统自带备份

### 1. macOS Time Machine
- **定价/容量**：免费。仅本地目标（USB/FireWire/Thunderbolt 盘、NAS over SMB），无官方云目标。
- **小白友好（业界标杆）**：插入外置盘即弹窗「用作用份磁盘？」一键开启；每小时自动快照；恢复是「星际穿越」式时间轴 UI，可进入 Photos 等 app 内直接浏览历史版本；换机走迁移助理。自动处理系统文件排除、电池供电暂停等细节。
- **隐私/加密**：可选加密 APFS 备份卷；数据不出本地/NAS，天然无云厂商可见性问题，但也没有异地容灾（盘被偷/火灾即全灭）。
- **平台**：仅 macOS。
- **抱怨**：macOS Tahoe(26) 升级后 NAS 备份因新 SMB signing 握手大面积失败（需 NAS 端配合修）；APFS sparsebundle 长期 bug；单盘单目标，无 3-2-1 引导。

### 2. Windows File History / Windows Backup
- **现状**：File History 已被微软停止开发（deprecated，工具仍在但不进未来策略）；「Backup and Restore (Windows 7)」已边缘化。现行方向是 **Windows Backup app（Win11）**：文件、文件夹、app 列表、设置、凭据全部推到 **OneDrive**。
- **定价**：OneDrive 免费 5GB；100GB $1.99/月；1TB 需 Microsoft 365 Personal $9.99/月。
- **小白友好**：开箱即用、账号绑定、换机可恢复 app 清单——引导做得好；但「系统镜像」藏在旧面板，本地/网络盘文件备份无未来。
- **隐私**：OneDrive 静态加密但**非零知识**（微软可及）。
- **抱怨**：File History 对网络盘/Samba 不可靠；备份能力实质上被绑死在 OneDrive 订阅与容量上；本地整盘备份在系统内几乎无现代方案。

### 3. iOS/iCloud 备份
- **定价（2026 美国）**：5GB 免费；50GB $0.99/月；200GB $2.99/月；2TB $9.99/月；6TB $29.99/月；12TB $59.99/月；支持家庭共享。
- **小白友好（标杆级）**：夜间充电+Wi-Fi 全自动；换机 Quick Start 近场迁移几乎零操作；恢复进度可视化。
- **隐私**：**Advanced Data Protection（ADP）** 免费开启后为端到端加密（含备份与照片）；不开则苹果持密钥；英国等地不可用。
- **抱怨**：5GB 免费额度形同虚设、升级弹窗骚扰；只覆盖苹果生态；ADP 是「懂的人才开」的隐藏开关。

### 4. Android（Google One 备份）
- **机制**：Settings → System → Backup；备份 app 列表、部分 app 数据（每 app 约 25MB 上限）、SMS、通话记录、设置、联系人；照片另走 Google Photos。Google 账户 15GB 免费。
- **抱怨**：恢复「无原因失败/不显示」；SMS/MMS 实际未被备份的案例；备份内容不透明、本地文件/录音/WhatsApp（自成体系）不覆盖。**结论：移动端备份普遍「不透明+不可验证」，是跨端产品的普遍空档。**

## 二、商业消费级备份

### 1. Backblaze Personal Backup（易用标杆 + 2026 信任危机主角）
- **定价**：$9/月；年付 $99（$8.25/月）；两年 $189（$7.88/月）。**无限容量**，限 1 台电脑+外接盘，每台机器一份订阅。
- **小白友好（正面教材）**：安装即默认备份全部用户数据，零配置；持续静默上传；恢复三通道：web zip（单次 ≤500GB）、恢复 app（无限）、**USB 硬盘寄回（30 天内寄回全额退款）**。
- **隐私**：默认非零知识（Backblaze 持密钥）；可选 Private Encryption Key——但丢钥即丢数据，且 PEK 对话框有多年未修 bug。
- **平台**：仅 Win/macOS，**无 Linux**；移动 app 只读。
- **2026 年关键抱怨**：
  - **2025 末起静默排除 iCloud Drive/OneDrive/Dropbox 等云同步文件夹及 .git**，恢复时这些文件不存在，2026 年成为 HN 千赞级信任危机（~1005 points/611 comments）。
  - 大恢复 RTO 数周、20TB+ 在线恢复不可用。
  - 外接盘断连/删除文件 30 天后删云端副本，有用户因此丢 12TB 家庭照片。
  - 恢复后发现文件从未被备份。

### 2. Backblaze B2（「自带后端」生态的基石）
- **定价**：$6.95/TB/月，**egress 免费至存储量 3 倍**，超出 $0.01/GB；10GB 永久免费层；S3 兼容。Arq/Kopia/Duplicacy 生态靠它压成本。注意：BYO B2 存 1TB ≈ $83/年，**并非总比 $99/年无限量的 Personal 便宜**——大容量用户的价格论证要谨慎。

### 3. Acronis True Image 2026（原 Cyber Protect Home Office，又改回旧名）
- **定价（1 设备/年，经销商价交叉印证）**：Essentials ~$49.99（无云存储）；Advanced ~$74.99（含 500GB 云）；Premium ~$124.99（含 1TB 云）。全订阅制，常年 30% 左右促销。
- **功能**：最全——整盘镜像+文件级+克隆+移动设备备份+防勒索/杀毒+Web 控制台远程管理。
- **平台**：Win/macOS/iOS/Android（macOS 版功能弱于 Windows 版）。
- **隐私**：Acronis 云非零知识。
- **抱怨（社区长期主题）**：捆绑杀毒/反恶意软件被称 bloatware；订阅年年涨价；镜像恢复需要启动介质，对小白仍是门槛。Linux 无消费版。

### 4. iDrive（唯一三桌面全覆盖的主流消费级）
- **定价**：免费 10GB；5TB $99.50/年（首年促销常见 ~$69.65）；10TB ~$149/年；20TB 更高。**容量在不限数量的设备间共享**（与 Backblaze 单机模式对比鲜明）。
- **功能**：文件备份+Snapshots 快照+磁盘镜像+NAS 备份；平台 Win/macOS/**Linux**/iOS/Android。
- **隐私**：AES-256，可选私有加密密钥；默认非零知识。
- **抱怨**：**续费涨价**（>5TB 档尤甚）；上传速度投诉；功能多但 UI 杂乱、体验割裂。

### 5. Carbonite（纯小白向，存在感下滑）
- **定价**：Basic $95.99/年（无限容量、1 台电脑）；Plus $131.99/年（+外接盘+视频备份）；Prime $161.99/年（+Courier 寄盘恢复）。
- **小白友好**：装完自动圈定文档等文件夹静默跑，几乎零决策。
- **抱怨**：Basic 默认不备视频、外接盘要加钱档；限速与慢恢复是历史性投诉；被 OpenText 收购后创新停滞。

### 6. Arq Backup（专业用户口碑之王，backguard 最直接对标）
- **定价**：**Arq 7 买断 $49.99/电脑**（含 1 年更新，之后续更新 $25/年可选）；**Arq Premium $59.99/年 = 5 台电脑 + 1TB Arq 云**，超出 $0.0059/GB/月。
- **后端自由度**：AWS S3、Backblaze B2、Wasabi、Google Storage/Drive、OneDrive、Dropbox、SFTP、外接盘、NAS、任意 S3 兼容端点（R2/MinIO）——**「软件归我、存储归你选」模式鼻祖**。
- **隐私**：**零知识客户端加密**（密码派生密钥），**备份格式开放且文档化**。
- **平台**：仅 macOS/Windows（macOS 版用 APFS 快照做时间点备份）；无 Linux。
- **抱怨**：配置门槛高（自己开云账户/配桶），小白劝退；单开发者 bus factor；支持仅邮件；无 Web 恢复门户（自有后端时）。

### 7. CrashPlan（Linux 用户老朋友，SMB 化）
- **定价（Small Business）**：端点 $7.33/用户/月（年付 $88），**无限存储+无限版本**；服务器档 $15.75/月含 250GB。个人版 2017 年已关闭。
- **平台**：Win/macOS/**Linux** 三桌面。
- **隐私**：AES-256 静态+每用户密钥（非严格零知识）；不可变备份；SOC2/ISO27001。
- **抱怨**：速度（Reddit 案例 1.1Mbps）；按用户计费不友好家庭；2017 背弃个人用户的信任阴影仍在。

## 三、云盘/同步类（与备份的边界）

- **定价（2026，2TB 锚点）**：Google One 2TB $9.99/月；Dropbox Plus 2TB $11.99/月；OneDrive 走 Microsoft 365 Personal $9.99/月含 1TB。
- **边界问题**：同步≠备份——删除、勒索加密会双向传播；版本历史有限（多为 30 天）。用户普遍误把「文件在云盘」当「有备份」。
- **Syncthing**：开源免费 P2P 设备互同步，无云端、无版本（是镜像复制不是备份）；配置是 Web UI，小白门槛高；大文件/海量文件性能与状态显示不准是长期抱怨。
- **Resilio Sync**：BitTorrent 协议闭源，WAN 速度优于 Syncthing 开箱表现；免费版限制最多 2 个「服务器」角色。

## 四、端到端加密云

### Filen（架构重点，现代「分块+客户端加密」样板）
- **定价**：10GB 免费；Pro I 200GiB €1.99/月、Pro II 500GiB €3.99、Pro III 2TiB €8.99、Pro X 10TiB €39.99；**档位可叠加、无上限**。
- **架构**（docs.filen.io）：
  - 文件**分块（chunk）加密**：每块用 AES-256-GCM + 随机 12 字节 nonce，上传字节流 = nonce||密文||authTag；
  - 主密钥由密码派生；元数据再经 PBKDF2(SHA512) 变换加密；
  - **文件名/目录树等元数据全部加密**（服务器零可见）；
  - 分享用 RSA + PKCS1-OAEP(SHA512) 非对称加密；
  - **全部客户端开源**（GitHub FilenCloudDienste），德国公司。
- **定位提醒**：Filen 是同步/存储产品（带版本），**不是版本化备份产品**——但其「分块+客户端加密+开源客户端+元数据加密」架构是 backguard 云传输层最值得借鉴的现成模型。

### 其余
- **Proton Drive**：5GB 免费；Plus 200GB $3.99/月（年付 $47.88）；零知识 E2EE、瑞士、开源客户端、全家桶捆绑。
- **MEGA**：20GB 免费；Pro Lite 400GB €4.99/月；Pro I 2TB €9.99；Pro II 8TB €19.99；Pro III 16TB €29.99。E2EE，但**月度流量配额**限制大额下载恢复。
- **Tresorit**：免费 3-5GB；Premium 500GB ~$10.42/月；Solo 2.5TB ~$24/月。零知识+企业合规，同类中最贵。
- **共同点**：全都不是备份产品（无自动全机备份/恢复引导），但证明了用户愿意为「零知识」付溢价。

## 五、NAS 生态（简述）

- **Synology Hyper Backup**：文件级+去重+增量+版本+AES-256，目标可为本地卷/USB/远程 Synology/rsync/11+ 种公有云；**专用 .hbk 格式**，恢复依赖官方工具（Explorer）——格式锁定被社区诟病。
- **Active Backup for Business**：块级整机镜像（PC/服务器/VM）、裸机恢复；**Active Backup for Home 已停更**，Synology 家用方向收缩、转向 ActiveProtect 备份专用硬件。
- **威联通**：Hybrid Backup Sync 同类（文件级+去重+多云目标），体验更杂。
- **门槛**：NAS 硬件 $300 起 + DSM 设置对小白不友好；但这是家用 3-2-1 最强基座，backguard 应把「NAS 作为目标/作为源」纳入设计而非对抗。

## 六、小白友好设计模式清单（业界已验证）

1. **零决策默认**：Backblaze「装完即备全部用户数据」、Time Machine「插盘即问」——默认覆盖一切、减少选择是最强降门槛手法。
2. **自动圈定重要文件夹**：Carbonite/Windows Backup 自动选 Documents/Desktop/Pictures；比让用户勾选树状目录损失率低得多。
3. **时间轴/快照式恢复 UI**：Time Machine 星际穿越界面是标杆；「右键→以前的版本」是 Windows 版廉价近似。恢复场景按「我想找回昨天误删的文件」组织，而非按存储结构组织。
4. **恢复多通道分层**：web zip（小）→ 恢复 app（中）→ USB/快递寄盘（大）。Backblaze 寄盘退款机制、Carbonite Prime Courier 已验证。
5. **换机迁移引导**：Apple Quick Start、Windows Backup 的 app 清单恢复——「备份的最大使用场景是换电脑」被苹果验证。
6. **静默运行+自适应节流**：后台持续/每小时快照，不抢 CPU/带宽/电池（Time Machine 电池暂停）。
7. **单一健康信号**：「上次备份 X 小时前」+ 桌面/App 红绿灯；iDrive/Backblaze 托盘状态灯。
8. **家庭/多设备共享计费**：iCloud 家庭共享、iDrive 无限设备共享池、Arq Premium 5 台——按「户」不按「台」显著降低决策负担。
9. **排除项透明化（反面教材价值最大）**：Backblaze 2025-26 静默排除云同步文件夹直接引发 HN 千赞信任危机——**「什么没被备份」必须显式、可审计、变更通知**。
10. **移动端只读访问+远程管理**：Backblaze/iDrive app 查文件、定位电脑——备份库变「随身硬盘」增强感知价值。
11. **地理化/内容化恢复视图**：照片产品（Google Photos 按人/地）已证明内容感知的组织方式价值；备份恢复 UI 无人做（空档）。
12. **恢复演练**：所有厂商只在文档里建议，无一做成产品功能（空档）。

## 七、专业用户看重的能力清单

1. **目标自由（BYO backend）**：S3/B2/Wasabi/R2/SFTP/NAS/本地/外接盘任意组合（Arq 模式）——成本与锁定双解。
2. **零知识客户端加密+密钥自持**：默认而非可选（对比 Backblaze PEK 的半吊子实现）。
3. **开放/文档化备份格式**：产品死了数据还能救（Arq 公开格式、restic/Borg 开源格式的社区共识）。
4. **去重+块级增量+可调版本保留**：CrashPlan 无限版本、Arq 精细策略是卖点；Backblaze 长版本保留要加价。
5. **数据完整性验证**：checksum、定期校验、恢复测试报告——Backblaze「恢复时才发现文件缺失」类事故的直接对策。
6. **Linux 一等公民**：Backblaze/Arq/Carbonite 均无 Linux；CrashPlan 有但 SMB 定价、iDrive 有但体验杂乱。三桌面原生是真实空档。
7. **速度与无限速**：多线程上传、不人为节流（CrashPlan 1.1Mbps、Carbonite 限速是黑历史）。
8. **CLI/API/无头模式**：服务器与自动化场景刚需。
9. **离线/断连策略透明**：Backblaze 30 天删除规则引发的 12TB 丢失类惨剧——策略必须可配置且高亮可见。
10. **买断或可退出**：订阅取消后数据的命运（导出/只读宽限期）；Arq 买断制在 HN 口碑中权重很高。

## 八、backguard 核心竞争优势候选（论证）

1. **「备份覆盖契约」透明化——直击 2026 年最大信任危机**。Backblaze 静默排除 OneDrive/iCloud/Dropbox/.git 引爆 HN 千赞帖，暴露全行业通病：用户不知道什么没被备份，恢复时才发现。backguard 可把「覆盖范围」做成第一公民：显式排除清单+变更推送+定期「覆盖审计报告」（含云同步占位文件、外接盘断连、30 天删除倒计时预警）。没有竞品系统性做这件事，且它把 Backblaze 的三大事故（静默排除、文件缺失、30 天删除）全部转化为可营销的对比点。
2. **三桌面原生统一引擎，Linux 一等公民**。Backblaze、Arq、Carbonite、Acronis 消费版均无 Linux；CrashPlan 有但 SMB 定价、iDrive 有但体验杂乱。「一个产品守护全家 Win+mac+Linux 设备」在 2026 年仍是空位，且与按户计费模式天然契合。
3. **「Backblaze 的易用 + Arq 的自由」双层产品**。默认层：零决策自动圈定重要目录+静默运行+时间轴恢复；专家层：任意目标（S3/B2/R2/SFTP/NAS/本地）+零知识加密+开放格式+CLI。Arq 证明专业市场存在且付费意愿强（买断 $49.99/台），Backblaze 证明小白市场巨大（$99/年无限），两者从未被同一产品同时满足——Arq 的小白流失和 Backblaze 的极客流失是同一批用户的两面。
4. **恢复优先（RTO 可视化+恢复演练）**。所有竞品的恢复都是事后补丁：数周 RTO（Backblaze 20TB+ 案例）、恢复时发现文件缺失、MEGA 流量配额限制恢复。backguard 可内置：定期自动抽样恢复验证+完整性报告（对专业用户是 scrub，对小白是「你的备份真的能用」绿色徽章）、恢复前预估时间、多通道恢复设计。这是把行业最大恐惧（备份恢复失败）变成日常可见指标。
5. **厂商中立开放格式+密钥自持，把「可退出」当卖点**。订阅时代的锁定恐惧（取消订阅后数据、产品停服后格式）是 HN/Reddit 反复出现的主题；Arq 公开格式与 Filen 全开源客户端分别验证了其口碑价值。backguard 公开文档化格式+客户端开源+密钥完全自持（默认零知识，不做 Backblaze 式可选 PEK），配合「一键导出」承诺，可把信任本身产品化——对一个新品牌，信任是唯一能以小博大的资产。
